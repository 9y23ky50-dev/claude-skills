# 내 스킬 백업

직접 만든 스킬 17개의 백업입니다. 각 `.skill` 파일은 zip 파일이고, 압축을 풀면 `스킬이름/SKILL.md`가 나옵니다.
설치 방법은 [저장소 README의 설치 방법](../README.md#설치-방법)과 같습니다.

> - 개인정보 보호를 위해 주문서 스킬은 넣지 않았습니다.
> - `three-keyword-brand-reel`은 올리기 전에 회사명·직함을 지웠습니다. 나머지는 계정에 있는 내용 그대로입니다.
> - 다른 사람이 만든 스킬(번역·요약한 것 포함)은 넣지 않았습니다.
