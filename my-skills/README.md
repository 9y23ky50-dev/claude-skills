# 내 스킬 백업

설치 방법은 [저장소 README의 설치 방법](../README.md#설치-방법)과 같습니다.

> 개인정보 보호를 위해 주문서 스킬은 넣지 않았습니다.
> `three-keyword-brand-reel`은 올리기 전에 회사명·직함을 지웠습니다. 나머지 22개는 계정에 있는 내용 그대로입니다.
